# Box Model

padding

Se usa para dar espacio interno entre el contenido y el borde del elemento.


border

Se usa para agregar un borde alrededor del contenido y el padding.


margin

Se usa para dar espacio externo entre un elemento y otros elementos.


box-sizing

Se usa para controlar cómo se calcula el tamaño total de un elemento.


# Unidades Absolutas y Relativas

px

Unidad fija.
Conviene usarla cuando se necesita un tamaño exacto.


%

Unidad relativa al tamaño del contenedor.
Conviene usarla para diseños adaptables.


em

Unidad relativa al tamaño de texto del elemento padre.
Conviene usarla para textos y espacios escalables.


rem

Unidad relativa al tamaño de texto raíz del documento.
Conviene usarla para mantener tamaños consistentes.


vw

Relativa al ancho de la ventana.
Conviene usarla para elementos que dependan del ancho de pantalla.


vh

Relativa al alto de la ventana.
Conviene usarla para secciones que ocupen toda la pantalla.


auto

Permite que el navegador calcule automáticamente el tamaño o espacio.
Conviene usarla para centrar elementos o adaptar tamaños automáticamente.
